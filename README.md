# Chhath Parv — GitHub Pages website

A responsive, single-page educational website about Chhath Puja. It includes:
- The meaning and significance of Chhath
- The four sacred days: Nahay-Khay, Kharna, Sandhya Arghya and Usha Arghya
- Ritual objects, samagri and prasad
- Chhath folk-song context, community care and FAQs
- Responsive navigation and CSS-created festival illustrations

## Publish on GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository (or open your existing repository).
3. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish your site.

No build tools or installation are required. Google Fonts are loaded online; the site itself works as a static HTML/CSS/JS project.

## Customization
- Edit page content in `index.html`.
- Change colours, layout and responsive styles in `style.css`.
- Navigation behavior and current year are handled in `script.js`.

## Cultural note
Chhath traditions vary by region and family. The site presents a general introduction, not a definitive ritual manual. Follow local and family customs for observance.
